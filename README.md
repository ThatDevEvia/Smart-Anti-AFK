# Smart Anti AFK

Smart Anti AFK is a modern Windows desktop app for Anti AFK automation, input recording, and macro playback.

Built with **.NET 10**, **WPF**, **C#**, and Windows API input hooks.

## Features

- Modern dark UI
- Theme support
- Anti AFK mode
- Randomized delay support
- Target app focus support
- Macro recording
- Macro playback
- Global keybinds
- Custom keybind settings
- Start with Windows
- Minimize to tray
- Tray notifications
- JSON-based recording storage
- One file per recording
- Safe stop controls

## Anti AFK

Smart Anti AFK can automatically keep a selected app active by bringing it to the front and sending controlled movement/input actions at timed intervals.

## Recordings

Create, record, play, rename, and delete recordings. Recordings are saved as JSON files and can be replayed with recorded delays.

## Keybinds

Customize global shortcuts for actions like:

- Stop Everything
- Toggle Recording
- Toggle Anti AFK
- Play Selected
- Skip Wait
- Force Kill App

## Settings

Available settings include:

- Start with Windows
- Minimize to Tray
- Randomize Delays
- Theme
- Playback Speed
- Interval
